## 안전한 검증 작업 목록

### 1. 로그인 페이지 (`/login`)
- [ ] 페이지 정상 로드 확인
- [ ] 이메일/비밀번호 입력란 표시
- [ ] 로그인 버튼 표시
- [ ] 관리자 계정으로 로그인 성공 → 대시보드 이동
- 📸 스크린샷 촬영

### 2. 대시보드 (`/`)
- [ ] 통계 카드 4개 표시 (콘텐츠, 콘텐츠 타입, 파일, 사용자)
- [ ] 콘텐츠 상태 요약 바 표시
- [ ] 최근 활동 테이블 표시
- [ ] 검색 입력란 표시
- 📸 스크린샷 촬영

### 3. 사이드바 메뉴
- [ ] 대시보드 메뉴 표시
- [ ] 콘텐츠 타입 메뉴 표시
- [ ] 파일 관리 메뉴 표시
- [ ] 콘텐츠 그룹 (동적 메뉴) 표시
- [ ] 사용자/권한 그룹 표시 → 클릭 시 하위 메뉴 펼침
- [ ] 외부 연동 그룹 표시 → 클릭 시 하위 메뉴 펼침
- [ ] 운영/데이터 그룹 표시 → 클릭 시 하위 메뉴 펼침
- [ ] 시스템 설정 메뉴 표시
- [ ] 그룹 클릭 시 아코디언 애니메이션 동작
- [ ] 한 번에 하나의 그룹만 펼쳐지는지 확인
- 📸 스크린샷 촬영 (펼친 상태)

### 4. 콘텐츠 타입 목록 (`/content-types`)
- [ ] 페이지 정상 로드
- [ ] 테이블에 이름, 고유주소, 필드 수, 생성일 표시
- [ ] "콘텐츠 타입 추가" 버튼 표시
- [ ] 수정(연필) 버튼 표시
- [ ] 삭제(휴지통) 버튼 표시
- 📸 스크린샷 촬영

### 5. 콘텐츠 타입 수정 (`/content-types/:id/edit`)
- [ ] 기본 정보 섹션: 이름, 고유주소, 설명 필드 로드
- [ ] 외부 사용자 권한: 회원 작성 가능, 자동 발행 체크박스
- [ ] 콘텐츠 옵션: 고유주소 사용, 처리 상태 사용 체크박스
- [ ] 입력 항목 정의: 필드 카드들 표시
- [ ] 필드 타입 종류 드롭다운 확인 (19종)
- [ ] 필드 타입 선택 시 하단에 설명 텍스트(help-text) 표시
- [ ] select/multiselect 필드에 "선택 옵션" 입력란 표시
- [ ] 드래그로 필드 순서 변경 가능
- 📸 스크린샷 촬영

### 6. 콘텐츠 목록 (`/contents/:slug`)
- [ ] 페이지 정상 로드
- [ ] 제목 컬럼에 📌(고정), 🔒(비밀) 아이콘 표시 (해당 시)
- [ ] 조회수 컬럼 표시
- [ ] 상태 배지 표시 (초안/발행됨 등)
- [ ] 검색 입력란 + 돋보기 버튼
- [ ] 상태 필터 드롭다운
- [ ] "콘텐츠 추가" 버튼 표시
- [ ] 수정/삭제 버튼 표시
- 📸 스크린샷 촬영

### 7. 콘텐츠 수정 (`/contents/:slug/:id/edit`)
- [ ] 기본 정보: 제목, 고유주소(useSlug 시)
- [ ] 게시판 옵션: 상단 고정 토글, 비밀글 토글
- [ ] 입력 항목: 동적 필드들 표시 (콘텐츠 타입에 따라)
- [ ] 버전 히스토리 펼침 버튼
- [ ] 하단: 취소, 저장, 발행 버튼
- [ ] 이전글/다음글 네비게이션 (글이 2개 이상일 때)
- 📸 스크린샷 촬영

### 8. 파일 관리 (`/media`)
- [ ] 그리드 뷰 기본 표시
- [ ] 테이블 뷰 전환 가능
- [ ] 업로드 버튼 표시
- [ ] 검색 입력란
- [ ] 타입 필터 (전체/이미지/영상/오디오/문서)
- [ ] 파일 카드 클릭 시 상세 팝업
- 📸 스크린샷 촬영

### 9. 역할/권한 목록 (`/roles`)
- [ ] 테이블: 이름, 고유주소, 설명, 권한 수, 사용자 수
- [ ] "역할 추가" 버튼
- [ ] 수정/삭제 버튼
- 📸 스크린샷 촬영

### 10. 역할 수정 (`/roles/:id/edit`)
- [ ] 기본 정보: 이름, 고유주소, 설명
- [ ] 권한 설정 섹션: 리소스별 체크박스 그룹
- [ ] 전체 권한(슈퍼 관리자) 토글
- [ ] 콘텐츠, 콘텐츠 타입, 파일 관리, 사용자, 역할, Webhook, 감사 로그, 시스템 설정 그룹 존재
- 📸 스크린샷 촬영

### 11. 사용자 관리 목록 (`/users`)
- [ ] 테이블: 이름, 이메일, 타입, 역할, 상태, 생성일
- [ ] "사용자 추가" 버튼
- [ ] 검색 입력란
- [ ] 타입 필터 (전체/관리자/회원)
- 📸 스크린샷 촬영

### 12. 사용자 수정 (`/users/:id/edit`)
- [ ] 기본 정보: 이메일, 이름, 비밀번호, 사용자 타입
- [ ] 계정 상태 토글 (활성/비활성)
- [ ] 역할 할당 체크박스 목록
- [ ] 저장/취소 버튼
- 📸 스크린샷 촬영

### 13. 감사 로그 (`/audit-logs`)
- [ ] 로그 테이블 표시 (사용자, 액션, 대상, 일시)

- [ ] 액션 필터 드롭다운
- [ ] 대상 필터 드롭다운
- [ ] 날짜 범위 필터
- [ ] 행 클릭 시 상세 팝업

### 14. Webhook 관리 (`/webhooks`)

- [ ] "시작하기 가이드" 버튼 → 팝업
