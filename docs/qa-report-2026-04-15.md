## 🔴 중대 버그

### 1. URL 직접 이동 시 세션 무효화
- Direct navigate(F5/주소창 입력)로 보호된 경로 이동 시 로그인 페이지로 강제 리다이렉트됨
- 특히 `/audit-logs`에서 일관되게 재현
- 사이드바 클릭(SPA 라우팅)은 정상 → 인증 가드/미들웨어의 초기 렌더 경로 문제로 추정

### 2. 사용자 수정 페이지 기본정보 pre-fill 실패
- 경로: `/users/:id/edit`
- 이름·이메일 필드가 비어있음 (placeholder만 노출)
- 역할 할당 영역은 정상 로드됨 → 부분 데이터 바인딩 버그

### 3. 감사 로그 사용자 컬럼 전부 "-"로 표시
- 총 364건 전부 사용자명이 "-"
- 사용자 ID → 사용자명 매핑 누락

   - 예: `<p>test</p><ul><li>...` 그대로 보임 → 이스케이프/plain text 추출 필요
6. **콘텐츠 목록 이미지 컬럼이 URL 문자열**로만 표시 (썸네일 미표시)

9. **사이드바 아코디언 규칙 불일치**
